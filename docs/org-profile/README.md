# ActionTokens

**Collect the real world.**

[app.action-tokens.com](https://app.action-tokens.com) · [ar.action-tokens.com](https://ar.action-tokens.com) · [org.action-tokens.com](https://org.action-tokens.com)

</div>

ActionTokens lets organizations issue their own action tokens and collectibles on [Stellar](https://stellar.org),
and lets fans collect them by walking to pins on a map, completing bounties and scanning murals in AR.

## Repositories

| Repository                                                                   | What it is                                                            |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [**actiontokens**](https://github.com/action-token/actiontokens)             | The platform: fan app, AR app, organization portal, worker, contracts |
| [actionverse](https://github.com/action-token/actionverse)                   | Deprecated. Replaced by `actiontokens`.                               |
| [gallery-actiontokens](https://github.com/action-token/gallery-actiontokens) | Deprecated. Replaced by `actiontokens`.                               |
